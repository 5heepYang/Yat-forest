## 四、数据模型

### tasks 字段使用（全部为 CONTRACT 已有字段，新增 1 个）

| 字段 | 本功能用法 |
| --- | --- |
| `taskId` | `db.newId('task')` 生成 |
| `userId` / `date` | 固定当前用户 / 当天 `YYYY-MM-DD`（复用 `mock.js` 的 `today()` 口径） |
| `slot` | 用户选的时间 `HH:mm`（`picker mode=time`） |
| `title` | 用户输入的事项原文 |
| `desc` | **AI 回填**：低碳实现方式，如「乘公共交通 · 少排约 140 g CO₂e」。创建时置 `''` 作为「待分析」识别标记 |
| `basePoints` | **AI 回填**：按低碳方式定级 |
| `done` / `carbonSavedG` / `aiComment` | 核验通过时由 `completeTask` 写入 |
| `proofImage` | `db.uploadImage()` 返回地址（云端 fileID / 本地 dataURL） |
| `proofText` | **新增字段**：文字凭证内容，string，可空。核验提交时暂存 |
| `reviewStatus` | `''` → 核验通过置 `'approved'` |
| `createdAt` | `db.stamp()` |

**待分析识别**：不加持久化字段，判定条件 = `date === 今天 && desc === '' && !done`。页面 `onShow` 时对满足条件的任务自动补一次分析，解决「分析中切页回来丢失回调」的问题；分析是幂等的，重复触发无副作用。

### 6.2 添加日程流

```
日历图标 onTap → openAdd()：sheetMode='add'，addSlot 默认当前时间
确认 onTap → confirmAdd()：
  1. 校验 addTitle 非空、addSlot 非空，否则 toast
  2. 组装 task（date=今天、desc=''、basePoints=0、done=false、
     proofImage=''、proofText=''、reviewStatus=''、createdAt=stamp()）
  3. store.addTask(task) → closeSheet → refresh()（新任务以「AI 分析中…」入列）
  4. planPending()：对 desc==='' 的今日任务调 aiPlanTask
     → store.updateTask(taskId, { desc, basePoints }) → refresh()
```

### 6.3 分组渲染

```js
function slotGroup(slot) {           // '08:00' -> '上午'
  const h = Number(slot.substring(0, 2))
  if (h < 12) return '上午'
  if (h < 18) return '下午'
  return '晚上'
}
```

今日任务按 `slot` 升序 → 按 `slotGroup` 分桶 → 每组 `label = 组名 · 最早slot - 最晚slot`。
wxml 双层循环：外层 `wx:for="{{groups}}" wx:key="label"`，内层复用现有 `task-row`。

### 6.4 凭证核验流（改造现有）

```
点日程行 → openTask()（现有）：已核验直接 toast 减碳量，未核验开弹窗
弹窗内容：拍照/相册按钮 + 文字凭证输入框 + 已选图片缩略图 + 提交按钮
选图片 → pickPhoto()：
  wx.chooseImage(count:1, sourceType:['album','camera'])
  → db.uploadImage(tempPath)（云/本地双模式，db.js 已备）
  → store.updateTask(taskId, { proofImage: url }) → setData 缩略图
  → 失败 toast('凭证上传失败，重试一次')，不阻断文字凭证路径
提交 → startVerify()：
  store.updateTask(taskId, { proofText })  // 文字凭证先暂存
  → sheetMode='loading'（dots 动画，现有）
  → aiVerifyProof(title, basePoints, proofText, cb) → sheetMode='result'
领取 → claim()：
  completeTask(taskId, carbon, comment, { proofImage, proofText })
  → toast('+N 积分已到账') → closeSheet → refresh()
    （积分变绿、今日碳能量/累计减碳量/进度条/周账本/streak 全部联动）
```

## 七、边界与异常

| 场景 | 处理 |
| --- | --- |
| 分析中切页 | 回来 `onShow` → `planPending()` 自动补分析（幂等） |
| 事项为空 / 时间为空 | toast 拦截，不入库 |
| 图片上传失败 | toast 提示；仍可用文字凭证走核验 |
| 重复核验 | `completeTask` 已有 `t.done` 防重入（store.js:259） |
| 旧数据无 `proofText`/`createdAt` | 读取侧按 `t.proofText \|\| ''` 兜底 |
| Storage 膨胀 | 历史任务保留（周账本需要），图片走 `db.uploadImage` 云模式存 fileID；本地模式 base64 由 db.js 注释的压缩建议兜底，1.0 演示量级可控 |
| 跨天 | 今日列表按 `date === today()` 过滤；昨日任务自动沉入历史（周账本数据源） |
