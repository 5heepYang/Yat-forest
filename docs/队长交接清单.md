> 写给队长：这一版的登录是**微信 openid 静默制**（一键进入，不同微信自动不同账号），

> 护林币经济（林地页完成任务后右侧手动领取、个人页换周边）、地图页进别人主页。
> 完整字段与接口见 `docs/CONTRACT.md`，本文只讲**你要动手做的事**。

## 一、一次性设置（约 5 分钟）

### 1. 确认 6 个集合已建（和之前一样）

云开发控制台 → 数据库 → `users` `trees` `tasks` `tree_logs` `goods` `records`，
每个权限：

```json
{ "read": true, "write": true }
```

> 不需要云函数、不需要第 7 个集合（账号密码版已撤下，改用 openid 静默登录）。

### 2. 验证全链路（5 步）

1. 开发者工具用**正式 AppID** 编译，Console 应出现 `[db] 云端模式`
2. 登录页点「微信一键登录」→ 直接进首页
3. 随便点一次「浇水」→ 云控制台 `trees` 里 `growthScore` 增加、`users` 的 `availablePoints` 扣减；护林币不再随浇水自动到账，去林地页成长任务右侧点「领取」（浇水 +15）
4. **用另一台手机/另一个微信**扫码进入 → 应是全新账号（0 碳积分、0 护林币、无树无日程），看不到你账号的任何数据
5. 你的号换设备重新进（同微信）→ 数据还在

第 4、5 步成立 = openid 隔离验收通过。

> 新号进来是零起点（0 碳积分 / 空日程 / 无树），首棵树可免费认养；
> 要演示数据就自己做几条日程、浇水施肥、上传实拍，护林币在成长任务右侧领取。

## 四、答辩问答准备

1. **为什么不用微信授权登录拿头像昵称**：微信 2022 年 10 月起收回该能力（getUserProfile 只返回匿名信息），官方替代是 chooseAvatar + nickname 组件，我们注册/资料弹层用的就是它
2. **为什么不用手机号登录**：手机号组件要求企业认证主体 + 按次付费（约 0.03 元/次），个人主体小程序无资格，学生作品不可用
3. **账号怎么隔离的**：微信 openid 由微信服务器在写库时自动注入、无法伪造，个人数据（积分/日程/日志/兑换）按 `_openid` 服务器端过滤， trees/goods 全局共享
4. **护林币经济**：日程任务赚碳积分 → 林地浇水/施肥/上传实拍（-积分 / +成长）→ 成长任务右侧手动领取护林币 → 补给站花护林币，三页形成闭环
