## 一、技术前提：这是 uni-app x，不是 uni-app

| 差异点 | 影响 |
| --- | --- |
| 文件是 `.uvue`，逻辑层是 **UTS**（强类型） | 所有数据必须声明 `type`，数组写 `Array<Tree>`，对象字面量要 `as Tree` |
| 开启了 **vapor 蒸汽渲染模式** | CSS 黑名单：`animation / transition / background-image / overflow / z-index / visibility / pointer-events / text-decoration` 都不支持 |
| 只用 class 选择器，**不支持关系选择器** | 不能写 `.a .b`，只能平铺类名 |
| 样式**不继承** | 文字样式必须写在 `<text>` 自己的 class 上，字体也要逐条声明 |
| 文字必须在 `<text>` 组件内 | `<view>` 里直接写文字会丢样式 |
| 没有 `z-index` | 层级只看 DOM 顺序，后面的兄弟节点盖住前面的 |

改样式前先跑一遍仓库内的自检脚本（可选，需要 Python）：

```bash
python .workbuddy/tools/check_uvue.py   # 检查裸文字 / 关系选择器 / 禁用属性
```

## 二、数据流

```
common/mock.uts  ──►  common/store.uts（reactive 单例）  ──►  页面只读渲染
                          ▲                        │
                          └──── 所有写操作函数 ◄──────┘
```

- 页面**不要**直接改 `store.xxx` 的字段（唯一例外：`/pages/tree` 里 PK 奖励 +50 积分，属临时写法，建议后续收敛）。
- 新增写操作时，在 `store.uts` 里加一个函数，返回 `''` 表示成功、返回中文提示表示失败，页面拿到非空就 `toast`。这是全局约定。

## 三、五个核心对象（`common/model.uts`）

| 类型 | 关键字段 | 说明 |
| --- | --- | --- |
| `User` | `userId, nickname, avatar, availablePoints, totalGrowthScore, days` | `availablePoints` 是可用碳积分（钱包），`totalGrowthScore` 是累计成长值（只增不减，用于 PK 与勋章） |
| `Tree` | `treeId, name, species, posX, posY, ownerId, level, growthScore, status, hazardText, age, distance` | `posX/posY` 是**百分比坐标**（0–100），直接映射到地图容器；`ownerId` 为空串表示待认养；`status` 取 `normal` / `hazard` |
| `CarbonTask` | `taskId, slot, title, desc, basePoints, done, carbonSavedG, aiComment` | `slot` 是 `08:00` 这样的时间段，页面拼成「上午 · 08:00 - 10:00」 |
| `TreeLog` | `logId, treeId, kind, imageUrl, description, aiAnalysis, rewardPoints, createdAt` | `kind` 取 `growth`（生长实拍）/ `hazard`（隐患工单），时光轴只筛 `growth` |
| `Souvenir` | `itemId, name, costPoints, stock, image, desc` | 兑换会扣 `stock` 并写入 `store.records` |

数值口径（`common/theme.uts`）：认养 300、浇水 -10/+20、施肥 -20/+50、隐患上报 +100、实拍 +20、今日目标 100 分。

## 四、AI 层契约（`common/ai.uts`）

四个函数都是**回调式**（不用 Promise，规避 UTS 泛型坑）：

```ts
aiVerifyProof(title: string, basePoints: number, cb: (r: AiProofResult) => void)
aiAnalyzeHazard(treeName: string, species: string, cb: (r: AiHazardResult) => void)
aiAdvice(done: number, total: number, cb: (text: string) => void)
```

1.0 内部是 `setTimeout` + 随机/规则模拟。接真实模型时：

1. 在 `ai.uts` 里把 `setTimeout` 内容换成 `uni.request`（先用 `uni.uploadFile` 把图片传到对象存储拿 URL）；
2. **回调签名不要改**，页面零改动；
3. 解析结果时保持字段：`AiProofResult{ passed, carbonSavedG, comment, detail }`、`AiHazardResult{ level, ticket, analysis, advice, reward }`。

> 「AI 树灵对话」在 1.0 已按产品决策移除，`ai.uts` 中保留了 `aiTreeSpirit` 未引用，需要时可重新接入。

## 六、已知限制（1.0 有意为之）

1. **状态不持久化**：数据活在内存里，重启 App 回到初始 Mock。需要持久化时在 `store.uts` 增加 `uni.setStorageSync` 的读/写即可，字段结构与 `AppState` 一致。
2. **AI 全部是模拟**：目的是保证答辩现场断网也能演示。
3. **地图是插画底图**：点位用百分比坐标，换成真实校园底图后按同一坐标系摆点即可，无需地图 SDK。
4. **字体体积**：HarmonyOS Sans SC Regular + Bold 共约 15.7MB，直接内嵌保证离线一致。要瘦身可用 `pyftsubset` 做子集（保留 3500 常用字 + ASCII），可压到 2MB 以内。
5. **仅 arm64**：uni-app x 蒸汽模式运行时只有 `arm64-v8a`，x86 模拟器会白屏，验收用真机。
