04 · 动效清单（建议新增 / 修正）

原则：所有动效 ≤ 300ms、只动 transform 与 opacity（不触发重排）、尊重"切页不抢戏"。第 1 条是本次卡帧修复的核心。

① Tab 切页入场（修卡帧）P0
根因见对话结论：预置动画的 setData 未等渲染层生效就执行了 switchTab，首帧仍显示旧画面，随后跳到动画起点，看起来像"一帧重复"。修复后统一为 240ms 位移 24px + 淡入，地图页保持纯淡入。
ease-out-cubic / 240ms / translateX(24px)→0 + opacity
② 弹层弹入 + 遮罩淡入P1
sheet 从底部 32px 上滑 + 遮罩 200ms 淡入；关闭反向 180ms。现有页面弹窗是瞬时出现，这是"AI 感"的主要来源之一。
sheet 260ms cubic-bezier(.22,.9,.35,1) / mask 200ms
③ 按压反馈P1
所有可点卡片与按钮 hover-class 压缩 scale(0.97) + 阴影收紧，松手回弹。给全局一致的"手感"。
scale .97 / 120ms
④ 进度条生长P1
碳积分 / 成长值进度条在页面入场后从 0 生长到目标值，一次触发，不循环。
width 600ms ease-out / onShow 触发一次
⑤ 卡片列表阶梯入场P2
页面首屏卡片依次上浮淡入（延迟 60ms 递增），只在前 4 张生效，避免滚动区卡顿。
translateY(14px)→0 / 260ms / stagger 60ms
⑥ 可领取徽章呼吸P2
林地页"领取 +N 护林币"金色胶囊 2s 呼吸一次（阴影+亮度），引导点击；已领取/待完成不动画。
2.2s ease-in-out infinite / 仅 claimable 态
⑦ 树灵气泡轻浮P2
林地页树灵天气气泡 3s 上下 2px 浮动，配合树插画轻微摇摆，让页面"活"但克制。
translateY ±2px / 3s loop
⑧ tabBar 切换P1
选中胶囊背景用 transition 平滑变色（现有 chip 已有此处理，tabBar 没有）；图标 140ms 微缩放回弹。
bg 180ms / icon scale 1→1.12→1
