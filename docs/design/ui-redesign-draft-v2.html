森系手账 · 中大森友会

第二版设计方向：自然博物志 × 手账编辑感。衬线标题与等距英文小字标建立编辑气质，暖纸底与细发丝线替代厚阴影，植物线稿做页面呼吸点。所有改动只落在样式层——布局骨架、功能与数据逻辑一律不动。

VERSION 2 · NOV 2026

与第一版的取舍 VS V1

V1 · 清新森系（第一版）
现代卡片流：圆角大卡 + 柔阴影 + 扁平插画，安全、轻快，接近头部 App 通用风格。

动效清单 04 · MOTION

与 V1 相同的原则：≤300ms、只动 transform/opacity。本版额外加一条"纸感"原则——动效曲线统一用缓出，杜绝弹跳，弹跳会破坏手账的安静感。

① Tab 切页入场（修卡帧）P0
修复 setData→switchTab 竞态（详见对话结论）：预置动画等渲染层落地后再切页。240ms 位移 24px + 淡入，地图页纯淡入。
ease-out-cubic / 240ms / translateX(24px)→0
② 弹层上滑 + 遮罩淡入P1
sheet 从 32px 上滑、遮罩 200ms 淡入；关闭反向 180ms。消除弹窗瞬现的"系统感"。
sheet 260ms / mask 200ms
③ 按压反馈P1
卡片与按钮 hover-class 统一 scale(0.98) + 轻微下沉，不用大压缩。
scale .98 / 120ms
④ 进度条生长P1
碳能量 / 成长值进度条入场后从 0 生长到目标值，一次触发。
width 600ms ease-out / 触发一次
⑤ 首屏卡片阶梯入场P2
前 4 张卡片依次上浮淡入，延迟 70ms 递增；滚动区内容不参与。
translateY(12px)→0 / 260ms / stagger 70ms
⑥ 可领取胶囊呼吸P2
金色"领取 +N 币"2.4s 呼吸（亮度 + 阴影），已领取/待完成保持静止。
2.4s ease-in-out infinite / 仅 claimable
⑦ 树灵气泡轻浮 + 树冠摇摆P2
气泡 3.2s 上下 2px；树冠插画 6s 极缓 ±1.2° 摇摆——页面活，但不吵。
float 3.2s / sway 6s / ±1.2deg
⑧ tabBar 胶囊过渡P1
选中态森林绿胶囊背景 180ms 过渡 + 图标 140ms 微缩放回弹。
bg 180ms / icon 1→1.1→1
